# Reference Code

This folder contains external or template state-space code kept for
comparison while developing the StateSpaceAlpha model.

- `ay_fft_filter.m`: matrix-form filter, smoother, and EM scaffold.
- `EM_parameters_kim_2018.m`: Kim SSMT EM reference implementation copied
  from the cloned `sgallos/SSMT` repository.
- `computeAMI_SMI.m`: simpler one-dimensional smoother reference.
- `kim_ssmt_2018/`: small source snapshot of the Kim SSMT-style code.

These files are references, not the primary analysis implementation.
