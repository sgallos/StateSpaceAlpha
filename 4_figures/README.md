# 4 Figures

Curated figures for collaborator review.

- `primary_delta_trajectory.png`: primary SSM posterior for `delta(a)`, where
  `delta(a)` is CP minus Control alpha power. Negative values mean CP has
  lower alpha power.
- `no_resampling_matrix_overlay.png`: posterior mean trajectories from all
  six no-subject-resampling runs.
- `no_resampling_matrix_delta_bands.png`: each no-resampling run shown with
  its posterior credible band.
- `profile_likelihood_heatmap.png`: profile-likelihood surface for Run F.
- `em_loglik_history.png`: EM log-likelihood history from the Step 4
  diagnostic run.

The most important figure for the meeting is
`primary_delta_trajectory.png`. The overlay and band-panel figures show how
sensitive the result is to hyperparameter choice.
